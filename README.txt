UMÓW WIZYTĘ — PWA

Zawartość:
- index.html — aplikacja do umawiania wizyt
- manifest.webmanifest — instalacja jako aplikacja
- sw.js — Service Worker / cache PWA
- config.js — konfiguracja Supabase
- icon-192.png — ikona PWA
- icon-512.png — ikona PWA

Aplikacja korzysta z tej samej bazy Supabase co terminarz właściciela.
Do działania rezerwacji potrzebne jest połączenie z Internetem.

Instalacja:
- komputer: otwórz stronę przez HTTPS i wybierz instalację aplikacji w przeglądarce;
- Android: Chrome → menu → Dodaj do ekranu głównego / Zainstaluj aplikację;
- iPhone/iPad: Safari → Udostępnij → Dodaj do ekranu początkowego.
